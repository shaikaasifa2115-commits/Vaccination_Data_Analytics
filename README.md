# Vaccination Data Analytics

## Project Overview

Vaccination Data Analytics is an end-to-end data analytics project focused on analyzing global vaccination and public-health data.

The project analyzes vaccination coverage, disease incidence, reported cases, vaccine introductions, and vaccination schedules across countries and years. The objective is to transform raw healthcare data into meaningful insights that can support public-health monitoring, resource planning, and data-driven decision-making.

The project uses Python for data cleaning and exploratory data analysis, MySQL for structured data storage and SQL analysis, and Power BI for interactive visualization and dashboard development.

---

## Problem Statement

Global vaccination datasets contain large volumes of information across countries, years, vaccines, diseases, and vaccination programs. It can be difficult to identify vaccination coverage patterns, disease trends, regional differences, and relationships between vaccination-related variables directly from raw data.

This project aims to clean, validate, analyze, and visualize vaccination and disease-related data to identify meaningful patterns and provide useful insights for public-health planning.

---

## Objectives

- Clean and validate vaccination datasets.
- Identify missing values, duplicate records, invalid values, and outliers.
- Perform exploratory data analysis using Python.
- Analyze vaccination coverage across countries, regions, vaccines, and years.
- Analyze disease incidence and reported cases.
- Study vaccine introduction trends.
- Analyze vaccination schedules and scheduled rounds.
- Analyze relationships between important numerical variables.
- Store datasets in a MySQL database.
- Develop interactive Power BI dashboards.
- Generate business-oriented public-health insights.

## Datasets

The project uses five major datasets:

### 1. Vaccination Coverage
Contains information about:

- Country
- Year
- Antigen/Vaccine
- Coverage category
- Target population
- Doses
- Vaccination coverage

### 2. Incidence Rate

Contains:

- Country
- Year
- Disease
- Denominator
- Incidence rate

### 3. Reported Cases

Contains:

- Country
- Year
- Disease
- Reported cases

### 4. Vaccine Introduction

Contains:

- Country
- WHO region
- Year
- Vaccine
- Introduction status

### 5. Vaccine Schedule

Contains:

- Country
- WHO region
- Year
- Vaccine
- Schedule rounds
- Target population
- Geographic area
- Age administered
- Source/comment
